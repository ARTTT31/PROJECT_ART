# Development install.
#
# requirements.in is the source of truth for the runtime set and
# requirements-dev.in for the test and lint tools. The compiled
# requirements.lock (runtime) and requirements-dev.lock (runtime + dev) are what
# CI and Render install
# (`pip install --require-hashes -r requirements.lock`). The locks carry the
# hashes of the Linux cp311 distributions, so they cannot install in a Windows
# venv — and this machine needs one to run the backend locally. This shim keeps
# `pip install -r requirements.txt` and `pip-audit -r requirements.txt` (the
# commands in README and docs/setup) working without a second copy of the pins,
# and it pulls in the dev set because a local checkout is where flake8, mypy and
# pytest run. Render never installs this file.
-r requirements.in
-r requirements-dev.in
