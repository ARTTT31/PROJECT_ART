# Development install.
#
# requirements.in is the source of truth for the dependency set, and
# requirements.lock is what CI and Render install
# (`pip install --require-hashes -r requirements.lock`). The lock carries the
# hashes of the Linux cp311 distributions, so it cannot install in a Windows
# venv — and this machine needs one to run the backend locally. This shim keeps
# `pip install -r requirements.txt` and `pip-audit -r requirements.txt` (the
# commands in README and docs/setup) working without a second copy of the pins.
-r requirements.in
