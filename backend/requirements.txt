# Database
# SQLAlchemy 2.1 made greenlet optional, where 2.0 pulled it in by itself on
# x86_64/arm64 — but the async engine imports it at runtime. Without the extra a

# an older pin) and then every deploy dies on
# "The SQLAlchemy asyncio module requires that the Python 'greenlet' library is
